# 液压压力与推力固件设计

## 目标

在 STM32F103C8T6 上使用 HAL 库读取 4-20mA 液压传感器，计算 0-30MPa 压力和油缸推力，并通过 USART1 与显示屏通信。显示屏协议的实际变量名和事件命令尚未填写，必须集中保留在一个明确的配置区，后续修改时不影响测量、计算和应用调度。

## 已确认的硬件条件

- 主频：8MHz 外部晶振，PLL 后系统时钟 72MHz。
- ADC：ADC1，PA0-PA7、PB0-PB1 分别为 IN0-IN9，十路均连接同一个 OPA333 缓冲输出，每路前有独立 10k 串联电阻。
- 传感器：24V 两线制，4-20mA 对应 0-30MPa。
- 电流电压转换：150R、0.1% 采样电阻。因此 ADC 目标输入范围为 0.6-3.0V。
- 参考电压：使用 ADC1 内部 VREFINT 计算实际 VDDA，不能将 VDDA 固定写成 3.3V。
- 显示屏：USART1，PA9/PA10，115200、8N1、DMA 收发。
- 调试串口：保留现有 USART3 与 VOFA DMA 发送代码。

## 模块与职责

### pressure_measure

负责 ADC1 校准、DMA 扫描、十路 ADC 码值筛选、VREFINT 读取、VDDA 换算、信号电压和压力计算。十路读数因来源相同而不是十路独立传感器；模块会对读数进行排序并去除异常值，再得到平均值，以降低单一 ADC 引脚或采样瞬态异常的影响。

压力计算：

```text
signal_voltage = adc_code / 4095 * vdda
pressure_mpa = (signal_voltage - 0.6) * 12.5
```

最终压力限制到 0-30MPa。显示值保留一位小数，但内部计算保留 float 精度。

### thrust_calculator

接收压力和缸径，计算油缸有效面积与推力：

```text
area_m2 = PI * (cylinder_d_mm / 1000)^2 / 4
force_n = pressure_mpa * 1,000,000 * area_m2
force_kgf = force_n / 9.80665
force_ton = force_kgf / 1000
```

单位状态仅存在 MCU 内部；切换后由同一计算结果转换为 N、kg 或吨。

### screen_protocol

负责 USART1 DMA 接收重启、字节帧缓存、屏幕协议解析和 DMA 发送。它不包含任何压力、ADC 或推力计算。

`screen_protocol.c` 顶部提供唯一的“用户协议配置区”，包括：

- 显示屏压力变量发送模板。
- 显示屏推力变量发送模板。
- 显示屏单位变量发送模板。
- 缸径设置命令识别规则。
- 单位切换命令识别规则。
- 帧结束符或帧格式。

这些项初始为空字符串或禁用状态，并以中文注释标记为“用户后续填写位置”。在填写前，屏幕收发函数安全返回，不会发送错误数据，也不会改变缸径或单位状态。

### app_control

负责初始化顺序和周期任务：启动 ADC 采集、启动显示屏 DMA 接收；固定周期读取最新压力，计算推力，并在屏幕协议配置完成后刷新显示变量。缸径仅在解析到合法屏幕命令后更新。单位切换仅在解析到合法屏幕命令后循环切换。

## 数据流

```text
4-20mA -> 150R -> 0.6-3.0V -> OPA333 -> ADC1 IN0-IN9
      -> ADC DMA + VREFINT -> pressure_mpa
pressure_mpa + cylinder_d_mm -> force_n -> 当前单位下的 thrust_value
pressure_mpa / thrust_value / unit -> USART1 -> 显示屏
显示屏缸径或单位命令 -> USART1 DMA -> screen_protocol -> app_control
```

## 边界与故障处理

- VREFINT 码值为零或异常时，不使用本轮数据更新压力。
- ADC 十路数据不足或异常时，保留上一轮有效测量值。
- 缸径必须在预设安全范围内才允许更新；具体默认值和范围由固件配置宏给出。
- USART1 接收超长帧、发送忙或未配置协议时，丢弃该帧或跳过本次刷新，不阻塞主循环。
- 所有显示字符串在生成时使用固定长度缓冲区和 `snprintf`，避免越界。

## 验证策略

- 将压力与推力纯计算逻辑拆为不依赖 HAL 的 C 函数，使用主机端测试覆盖：0/4/20mA 对应压力、边界钳位、缸径推力、三种单位换算、异常 ADC 数据筛选。
- 在 MCU 编译时检查 HAL 工程能够通过编译。
- 上板后通过已保留的 USART3/VOFA 观察 VDDA、ADC 平均码值、信号电压、压力和推力，使用已知电流源或传感器实际压力做校准。

## 不在本次实现范围内

- 显示屏的实际变量名、事件字符串和帧格式；只提供集中、注释清晰的占位配置区。
- 压力传感器多点标定参数写入 Flash；首版使用理论 4-20mA 到 0-30MPa 换算。
- 十个 ADC 引脚发生硬件故障后的自动诊断和告警界面。
